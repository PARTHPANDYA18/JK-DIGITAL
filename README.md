# JK Digital Solutions 🚀

A modern, high-converting digital agency website for **JK Digital Solutions**, built with cutting-edge web technologies to showcase graphic design, video editing, social media marketing, and web development services.

---

## ✨ Features

- **⚡ Modern Dark Theme & Glassmorphism**: Tailored cyber-luxe dark palette with vibrant violet/indigo ambient glows and smooth backdrop blurs.
- **🎨 Interactive Portfolio Bento Grid**: Filterable showcases for Social Media Creatives, Branding & Identity, and Video Editing with hover reveals.
- **🔄 Before & After Image Comparison Slider**: Interactive draggable comparison slider demonstrating real retouching and design transformations.
- **📱 Floating WhatsApp Quick-Connect**: Direct one-tap WhatsApp chat integration (`+91 8401296111`) with floating pulsing indicator.
- **💬 Interactive FAQ Accordion**: Seamless accordion answers addressing turnaround times, revision policy, pricing, and onboarding.
- **🎉 Book a Strategy Call Modal**: High-conversion lead capture form with instant interactive validation and celebratory confetti trigger.
- **🌊 Butter-Smooth Scrolling**: Powered by `@studio-freight/lenis` for smooth momentum-based scrolling.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/) & [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Micro-Interactions**: `canvas-confetti`, `lenis`

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/PARTHPANDYA18/JK-DIGITAL.git
cd JK-DIGITAL
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the site.

---

## 📦 Build for Production

```bash
npm run build
npm run start
```
